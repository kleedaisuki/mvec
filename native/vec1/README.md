# SQLite Vec1

`vec1.c` is unmodified SQLite upstream source at
[3b657e60](https://github.com/sqlite/sqlite/blob/3b657e60de94d23aa79144c1dfd148ac02865909/ext/vec1/vec1.c).
`sqlite3.h` and `sqlite3ext.h` are the public extension headers from
[SQLite 3.54.1](https://sqlite.org/2026/sqlite-amalgamation-3540100.zip).
These public-domain sources carry their upstream notices. Only the extension
is compiled here; Microsoft.Data.Sqlite supplies the SQLite engine.
